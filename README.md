# 鼹鼠仔 · 课程资料（学生端）

这个仓库存放**老师已经发布**的课程资料，以及学生端面板插件。
没有发布的课时，在这里是**不存在的**——不是藏起来，是根本没有。

## 零、从零装到能用（新电脑照着走）

> 这一节是给**一台什么都没装过的 Windows 电脑**写的。
> 每一步都给了**判据**——跑那条命令看结果对不对，不对就别往下走。

### 0.1 先装两个软件（装完必须重开 PowerShell）

| 装什么 | 为什么必须 | 去哪装 |
| --- | --- | --- |
| **Node.js ≥ 20** | DSH 和面板都跑在它上面 | <https://nodejs.org> 选 **LTS** |
| **Git for Windows** | 面板组件要从 git 依赖里取包，**需要 git 在 PATH 里** | <https://git-scm.com/download/win> |

```powershell
# 关掉 PowerShell，重新打开，然后：
node --version      # 期望 v20.x 或更高
git --version       # 期望 git version 2.x
```

两条都打印版本号才算过。报「不是内部或外部命令」= 没装好，或没有**重开终端**。

> ⚠️ **Git 最容易被跳过，然后卡在安装最后一步。**
> 缺 git 时报的是 `ERR_PNPM_GIT_RESOLVE_FAILED ... git executable not found on PATH`，
> 看着像仓库坏了，其实只缺一个软件。

### 0.2 clone 本仓

```powershell
cd $env:USERPROFILE\Desktop
git clone https://github.com/fadedfakers/DSH-algorithm.git
cd DSH-algorithm
```

判据：

```powershell
Test-Path .\install.ps1, .\panel\dsh-course-student\package.json    # 期望两个 True
```

> clone 到哪都行。安装脚本会把**你 clone 到的这个路径**写下来告诉面板，
> 所以**之后别随手挪这个目录**——挪了要重跑一次 `install.ps1`。

### 0.3 跑一键安装

```powershell
powershell -ExecutionPolicy Bypass -File .\install.ps1
```

脚本做的事、以及**装完怎么验证**（三条从易到难的判据）见下面第四节。

### 0.4 装不上时的速查

| 症状 | 多半是 | 怎么修 |
| --- | --- | --- |
| 第 0 步报「本仓缺少这些文件」 | clone 不完整，或不在仓库根目录跑 | 确认上面的 `Test-Path` 是 True；否则删掉重新 clone |
| `git executable not found on PATH` | **没装 Git**，或装了没重开终端 | 跑 `git --version`；不行就装 Git for Windows 后**重开 PowerShell** |
| `ERR_PNPM_GIT_RESOLVE_FAILED` / `could not connect` | 到 github.com 的网络抖动 | 等一会儿**重跑同一条命令**（它是幂等的，重复跑没事） |
| 提示 `pnpm not found` | 没装 pnpm | `npm i -g pnpm`，再重跑 `install.ps1` |
| 面板图标**不出现** | 学生端和内核没一起装 | 两个包都要：`panel\dsh-course-core` 与 `panel\dsh-course-student` |
| 面板出现但**一片空白** | 工作区没配对 | 看第四节的判据②；`workspaceResolved` 与 `workspaceLooksValid` 都要 True |
| 接口报「未知动作：xxx」 | DSH 还是旧进程 | **重启 DSH**（关掉重开 `start.ps1`），不是刷新浏览器 |
| 换了电脑 / 挪了目录之后面板空了 | 工作区路径失效 | 在新位置**重跑一次 `install.ps1`**（它会重写路径） |

## 二、怎么提问（用面板，不用 Issues）

装好面板（见第四节）之后，所有提问都在**面板里**完成：

```
课件页 → 框选一块（公式/图表/讲义截图都行）→ 写问题 → 提交
```

提交后会依次发生三件事：

1. **凝练标题**：模型把你的问题压成一句统一风格的标题（长问题也能一眼看懂）
2. **AI 作答**：基于你框的那块内容和教案作答
3. **生成问题总结**：两三句话说明这条问题在问什么

### 你的问题默认只有你能看到

这是刻意的设计，不是限制：

- 你的提问落在**你自己电脑上**的私有目录里，别人看不到
- **老师也看不到** —— 除非你在「我的提问」里点「公开给老师」
- 老师看到并答复后，如果他判断这条对全班有价值，会把它公开给全班

**为什么要你手动公开**：一次作业批改会判出十几条问题，如果全自动推给老师，
他一天要面对几百条，最后只能不看。让他只看你主动送上来的那几条，
每一条才会被认真看。**选择权在你手上，这是为了让你的问题真的被回答。**

### 好的提问长什么样

- 说清**卡在哪一句**：「教案里说鞍点处 Hessian 有负特征值，我不理解为什么负特征值
  就一定是鞍点而不是极大值」
- 说清**你试过什么**：「查了维基，但那里的判据说要用二阶导矩阵的行列式，
  跟教案里的特征值说法对不上」
- 报错就**把报错原文贴上来**（可以直接 Ctrl+V 粘贴截图）

### 差的提问

- 「第 8 课看不懂」—— 不知道你看不懂哪一句
- 「代码报错了」—— 没有报错原文，没法判断
- 贴一整屏代码但没说期望什么、实际得到什么

## 四、关于 AI 答疑：用你自己的 API

**重要：这个面板跑在你自己电脑上，用你自己的 API Key。**

- 你的 Key 只存在你本机（`~/.dsh/.credentials.yaml`）
- 提问消耗的是**你自己的额度**，不经过老师的服务器
- 老师看不到你的 Key，也看不到你没公开的对话

### 一键安装（推荐）

在本仓根目录打开 PowerShell，跑一条就够：

```powershell
powershell -ExecutionPolicy Bypass -File .\install.ps1
```

它会依次做这些事：

1. 确认本仓完整（课程数据与插件都在）
2. 检查 Node.js（>= 20）
3. 检查 DSH，没装就装
4. 从**本仓自带的** `panel/dsh-course-student` 与 `panel/dsh-course-core` 安装面板插件
   （学生端 + 共享内核两个包；教师端那个包在老师机器上，你不用装）
5. 把「课程工作区」指向你 clone 下来的这个目录，并说明你的学生身份名
6. 指引你配置自己的 API Key，然后启动

**想先看它要做什么、不实际改动**：

```powershell
powershell -ExecutionPolicy Bypass -File .\install.ps1 -DryRun
```

脚本**不下载任何第三方代码**，只调用 `npm` 和 `dsh`。插件就在本仓 `panel/` 下，
是纯文本 JS，你可以自己打开逐行看它做了什么。

### 装完怎么验证（三条判据，从易到难）

先启动：

```powershell
powershell -ExecutionPolicy Bypass -File .\start.ps1
```

浏览器打开它给出的地址（通常是 <http://127.0.0.1:3080>），**侧栏底部**会出现
「课程问题池」图标。然后逐条核：

```powershell
# ① 面板挂上了吗 —— 样式表能取到就说明插件在服务
(Invoke-WebRequest http://127.0.0.1:3080/cip-stu.css -UseBasicParsing).StatusCode
# 期望 200

# ② 课程工作区配对了吗 —— 这是「面板为什么是空的」的唯一判据
$r = Invoke-WebRequest http://127.0.0.1:3080/cip-stu-api/info -Method POST `
     -Body '{}' -ContentType 'application/json' -UseBasicParsing
($r.Content | ConvertFrom-Json) | Select workspace, workspaceResolved, workspaceLooksValid
# 期望：workspace = 你 clone 的目录；后两个字段都是 True

# ③ 能打开一节课的教案吗 —— 端到端通了
$b = '{"lesson":7}'
$r = Invoke-WebRequest http://127.0.0.1:3080/cip-stu-api/lesson.open -Method POST `
     -Body $b -ContentType 'application/json' -UseBasicParsing
($r.Content | ConvertFrom-Json) | Select title, planRel
# 期望：返回课时标题与教案路径
```

> ③ 用的是**学生端**前缀 `cip-stu-api`，动作名要带在路径里，而且**必须用 POST**。
> 直接 GET `/cip-stu-api` 会返回 404 —— 那不代表没装好。

三条都过 = 开箱即用成功。任何一条不过，回上面 0.4 的速查表。

### 拿到老师新发布的内容

老师在老师机上把新内容推上来之后，本机这份不会自动更新。在面板顶部点
**「刷新」旁的同步入口**（或「公开问答」页的拉取按钮），它会做一次
`git pull --ff-only` —— 只快进合并，不产生 merge commit，
**绝不会碰你自己的提问**（它们在 `.gitignore` 里）。

## 五、关于作业

作业就在面板里交，**不用另外发邮件或传文件给老师**：

```
左侧课时脉络 → 点一个课时 → 「我的提交」→ 写/传/拍 → 提交并批改
```

支持三种方式，可以组合：

| 方式 | 适合什么 |
| --- | --- |
| **打字** | 推导过程、实验结论、设计说明；手推公式可以用文字/符号写 |
| **文件** | `.py` / `.ipynb` / `.md` / `.pdf` / `.zip` 等，单个 ≤ 8 MB，最多 6 个 |
| **图片** | 选图片，或**直接 Ctrl+V 粘贴截图**；也可以从课件上框一块收进来 |

AI 会**按教案逐条对照**批改，每条结论都带证据。它判出的问题**默认不公开**，
你可以去「我的提问」里挑要公开给老师的。

**每一次提交都是一个新版本**，旧版和旧版的批改都保留 —— 改完再交一版即可，
不会覆盖。面板顶栏的「提交历史」里能看到全部版本（与课时无关，按时间倒序）。

## 六、什么内容会被公开（以及为什么有些不会）

公开发布是**老师显式勾选**的结果，不是自动同步。以下内容**默认不公开**：

- 未定稿的教案与草稿
- 其他同学的原始提问与作业
- 评分维度与批改细节（公开与否属于教学决定）
- 课堂录音、录播源文件

你自己的提问**默认也不公开**，要你手动选择才会给老师看（见第二节）。

如果你认为某份资料应该公开但没有，**在面板里问一句**，比在群里问更不容易漏掉。

## 七、请不要做的事

- 不要把本仓库内容转发到公开平台（课件与教案属于课程材料）
- 不要在公开的地方贴自己的 API Key、密码、学号全号
- 不要手动改 `课程中心/_插件源码/` 与 `panel/` 下的文件后不说明 ——
  那些是插件本体，改了会与老师那份不一致，出问题时很难判断是谁改的

## 八、出问题了怎么办

| 症状 | 先做什么 |
| --- | --- |
| 面板显示「未知动作：xxx」 | 宿主半区没重启。关掉重开一次 |
| 打开诊断页自查 | 浏览器访问 `http://127.0.0.1:3080/cip-stu-diag/` |
| 作品图片/公式显示不出来 | 检查 `课程中心/预览数据/media/` 下有没有对应图 |
| 数据像是旧的 | 删掉 `课程中心/.cache` 后刷新（那只是缓存，删了会重算） |
| 同步拉不到更新 | 你可能改过本仓的文件导致不能快进合并；先 `git status` 看一眼 |

提问里带上**诊断页的截图**，老师能直接定位。
