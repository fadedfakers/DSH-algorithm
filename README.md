# 深度学习课程 · 课程资料（学生端）

这个仓库存放**老师已经发布**的课程资料。没有发布的课时，在这里是**不存在的**——不是藏起来，是根本没有。

---

## 一、你能在这里看到什么

| 目录 | 内容 |
| --- | --- |
| `课程.json` | 已发布内容的清单（哪些课时有资料、路径在哪）。**先看这个。** |
| `教案/` | 已发布课时的详细教案（含学习目标与验收标准） |
| `代码示例/` | 已发布的代码模板与检查清单 |
| `FAQ/` | 已沉淀的常见问题（老师审核过才会出现在这里） |

`课程.json` 里的 `publishedLessons` 告诉你当前发布了几课时。**如果你要的课时不在清单里，说明老师还没发布，去提 issue 问，不要去找"隐藏文件"——没有隐藏文件。**

---

## 二、怎么提问

用本仓库的 **Issues** 提问，不要用 Discussion、不要发邮件、不要在群里 @ 老师然后指望被记录。

提问入口：点上方 `Issues` → `New issue` → 选「课程提问」模板。

**提问前请先做两件事：**

1. 搜一下 Issues 里有没有人问过同样的问题（包括已关闭的）
2. 看一下 `FAQ/` 里有没有

### 好的提问长什么样

```
课时：课时8（损失曲面几何与优化器推导）
卡在哪：教案里说"鞍点处 Hessian 有负特征值"，我不理解为什么
       负特征值就一定是鞍点而不是极大值
我试过：查了维基，但那里的判据说要用二阶导矩阵的行列式，
       跟教案里的特征值说法对不上
```

### 差的提问

- 「第 8 课看不懂」——老师不知道你看不懂哪一句
- 「代码报错了」——没有报错原文，没法判断
- 贴一整屏代码但没有说明你期望什么、实际得到什么

## 四、关于 AI 答疑：用你自己的 API

本课程配套一个 DSH 面板，可以在课件/教案上框选提问、让 AI 即时作答，并把问题归档。

**重要：这个面板跑在你自己电脑上，用你自己的 API Key。**

- 你的 Key 只存在你本机 `~/.dsh/.credentials.yaml`
- 提问消耗的是**你自己的额度**，不经过老师的服务器
- 老师看不到你的 Key，也看不到你没提交的对话

安装与配置步骤见 `docs/学生端接入.md`。

### 一键装置（推荐）

在本仓根目录打开 PowerShell，跑一条就够：

```powershell
powershell -ExecutionPolicy Bypass -File .\install.ps1
```

它会依次做这些事：

1. 确认本仓完整（课程数据与插件都在）
2. 检查 Node.js（>= 20）
3. 检查 DSH，没装就装
4. 从**本仓自带的** `panel/dsh-course-student` 与 `panel/dsh-course-core` 安装面板插件
   （学生端 + 共享内核两个包；教师端那个包在老师机器上，你不用装）
5. 把「课程工作区」指向你 clone 下来的这个目录，并说明你的学生身份名
6. 指引你配置自己的 API Key，然后启动

**想先看它要做什么、不实际改动**：

```powershell
powershell -ExecutionPolicy Bypass -File .\install.ps1 -DryRun
```

脚本**不下载任何第三方代码**，只调用 `npm` 和 `dsh`。插件就在本仓 `panel/` 下，
是纯文本 JS，你可以自己打开逐行看它做了什么。

## 五、关于作业

- 作业提交方式以课堂通知为准（本仓库不接收作业，作业提交路径由老师单独指定）
- **作业正确答案不会提前发布**。老师批改并讲评之后，才会把参考答案或优秀答案发布到 `作业/` 目录
- 如果你在 `作业/` 里看不到本次作业，说明还没到发布时机

## 六、什么内容会被公开（以及为什么有些不会）

公开发布是**老师显式勾选**的结果，不是自动同步。以下内容**默认不公开**：

- 未定稿的教案与草稿
- 其他同学的原始提问与作业
- 评分维度与批改细节（公开与否属于教学决定）
- 课堂录音、录播源文件

如果你认为某份资料应该公开但没有，**提 issue 说明理由**——这是有效的反馈，比在群里问更不容易漏掉。

---

## 七、Issue 处理节奏

- 老师或助教会**定期**集中处理 issue（不是实时）
- 被判定为「**有代表性**」的问题会沉淀进 `FAQ/`，届时会在这里公开回复
- 紧急问题（影响你交作业）请在 issue 标题里加 `【紧急】`，并说明截止时间

---

## 八、请不要做的事

- 不要把本仓库内容转发到公开平台（课件与教案属于课程材料）
- 不要替其他同学提交 issue（会丢失提问人信息，也没法针对性回复）
- 不要在 issue 里贴自己的 API Key、密码、学号全号
